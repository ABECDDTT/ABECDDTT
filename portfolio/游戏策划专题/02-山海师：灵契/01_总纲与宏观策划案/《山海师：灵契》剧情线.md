# 序章：梦入山海（最终版）

> **设计原则**：全程无左上角弹窗，无强制跟随NPC。以「光圈山海师·无名氏」为唯一引导者，通过水墨晕染、呼吸光效与极简手势图标完成沉浸式教学。玩家从「现代人入梦」切入，在梦境中掌握全部核心操作与契约法则，梦醒后直接进入开放世界。

## 2.1 入梦（黑屏开场）

【场景】纯黑屏幕。中央有微弱的呼吸光晕，模拟闭眼时视网膜残留的视觉。

【音效】极远的风声 → 一滴墨汁落入宣纸的「嗒」声 → 古琴泛音，由远及近。

【演出】屏幕中央，一滴浓墨垂直落下。触底的瞬间，墨色如活物般向四周晕开，形成完美的圆形墨斑。墨斑从浓黑渐变为青绿，露出「山海师：灵契」五字。毛笔书写动画，一字一顿，共五秒。

【系统文字】（淡入，宣纸底色，毛笔字体，无窗口边框）

plain

```plain
你做了一个很长的梦。
梦里有人对你说——
"万物有灵，唯契者通。"
```

【演出】标题字缓缓消散，如被水晕开的墨痕，最后一笔拖得很长，像是谁不舍地收住了笔锋。屏幕重新归于漆黑。

【演出】黑暗中，七颗微弱的白色光点从屏幕边缘浮现，如夏夜流萤，向中心缓缓聚拢。光点汇聚成一条蜿蜒的光路，指向远方不可见的深处。

## 2.2 灵契之间（光圈山海师登场）

【场景】「灵契之间」——纯白水墨空间。地面是流动的淡墨波纹，每一步都会漾开涟漪，涟漪扩散三圈后归于平静。远处有青绿山水的剪影在雾中缓缓平移，如同一幅被无形之手不断展开的卷轴。

【演出】玩家角色以「剪影形态」从屏幕下方走入画面中央。无人形细节，只有轮廓与一柄武器的虚影。角色脚下自动生成淡金色水墨涟漪。

【角色】**光圈山海师**（无实体。一团直径约为角色身高1.5倍的柔和白色光晕，光晕边缘有淡墨拖尾缓缓飘散，如同呼吸。无面部，但光晕亮度会随语调起伏，明亮时如旭日，低沉时如残烛。声音为中性温和，带轻微山谷回音）

【对话】

**光圈山海师**：  
"你来了。"

**光圈山海师**：  
"不必惊慌，这里是'灵契之间'——山海界与现世之间的缝隙。每一个即将成为山海师的人，都会在此留下第一个脚印。"

【演出】光晕轻轻闪烁两下，如同眨眼。它向前飘动三个身位，停在角色正前方，地面留下一条持续五秒后缓缓消散的淡金色光痕。

**光圈山海师**：  
"我乃初代山海师，名讳早已散入风中。你叫我'无名氏'即可。"

**光圈山海师**：  
"我留在此地的，不过是一缕残识，只为等候能听见'灵契'召唤的有缘人。"

【演出】光圈微微明暗，仿佛在打量玩家。光晕中浮现出极淡的山水虚影，一闪而逝。

**光圈山海师**：  
"你的灵根很干净，像一张未落墨的宣纸。"

**光圈山海师**：  
"但在落笔之前，你需要知道如何握笔。"

## 2.3 基础操作教学（剧情化嵌入）

### 【教学点1：WASD移动】

【系统提示】（屏幕右下角，淡墨毛笔字，不遮挡画面，五秒后自动淡化）

plain

```plain
[提示] 按下 W A S D 移动
```

【演出】光圈山海师向前飘去，速度不快，恰好是玩家正常行走的速度。它经过的地方，地面留下一条淡金色的光痕，光痕两侧有细小的墨梅凭空绽放，又迅速化为墨点消散。

**光圈山海师**：  
"很好。脚步要轻，心意要沉。山海界的土地会记住每一个踏过它的人。"

**光圈山海师**：  
"跟上来。我带你去看看'契约'真正的模样。"

【演出】光圈移动到前方约十个身位处停下。路径两侧浮现出几缕黑色的「妄念之影」——小型黑色墨团，无攻击意图，只是梦境中浊气的具象，如同游鱼般缓缓游动。

---

### 【教学点2：鼠标左键普攻】

【演出】光圈停在一团较大的妄念之影前。黑影开始蠕动，膨胀，最终变成一只简笔画风格的野兽轮廓——只有墨线勾勒的狼形，无填充色，双眼两点猩红，张口无声咆哮。

**光圈山海师**：  
"这是'妄念'。心魔未净时，梦境中常有的浊物。"

**光圈山海师**：  
"山海师不以蛮力称雄，而是以'念'为刃。你的意志，就是最锋利的武器。"

**光圈山海师**：  
"挥动它，击碎这团浊气。"

【系统提示】

plain

```plain
[提示] 按住鼠标左键进行普攻三段连段
```

【演出】玩家攻击妄念之影。每次命中，黑影溅出细小的墨点，发出纸张被轻轻撕裂的脆响。第三段连击时，角色武器拖出一道淡金残影，黑影应声破碎，化作漫天墨雨落下，落地前即消散为虚无。

**光圈山海师**：  
"利落。你的念，比我想象的更通透。"

### 【教学点3：闪避机制】

【演出】远处突然凝聚出三团妄念之影，呈品字形向玩家快速飘来。速度适中，给玩家1.5秒反应时间，碰撞体积友好，不会主动绕后。

**光圈山海师**：  
"小心！妄念聚而不散，会反噬心神。"

**光圈山海师**：  
"不要硬接。身如流水，意如游鱼——躲开它。"

【系统提示】

plain

```plain
[提示] 按鼠标右键进行基础闪避（0.3秒无敌帧，消耗25耐力）
[提示] 按空格键释放职业特色位移（后续解锁）
```

【演出】玩家闪避成功时，角色身后拖出一道清晰的水墨残影，时间缓速0.2秒，能清楚看到妄念之影扑空的轨迹。黑影撞在地上，碎成几滴墨汁，渗入地面波纹中。

**光圈山海师**：  
"漂亮。闪避不是怯懦，是为了找到更好的出手机会。"

【演出】若玩家被击中，角色剪影闪烁暗红，屏幕边缘泛起淡红色水墨晕染，伴随一声沉闷的钝响。光圈山海师光晕微微暗淡，发出一声轻叹。

**光圈山海师**（受击分支）：  
"无妨。疼痛也是契约的一部分。记住这种感觉，它会让你在真正的战斗中更谨慎。"

【演出】妄念之影重新凝聚，速度降低20%，直到玩家成功闪避为止。若连续三次未成功，光圈山海师会轻轻叹息，黑影自动消散，教学强制通过。

---

### 【教学点4：空格职业特色】

【演出】光圈飘回场地中央，地面升起三座石台，分别刻有「御」「战」「术」三字。

**光圈山海师**：  
"方才的闪避，是所有人的本能。但每一位山海师，都有自己独特的'身法'。"

**光圈山海师**：  
"按住空格，感受你体内的灵根偏向。"

【系统提示】

plain

```plain
[提示] 按住空格键体验职业特色（当前为演示模式）
[提示] 灵战士：铁壁格挡 / 驭灵师：灵兽瞬闪 / 灵术师：元素遁
```

【演出】玩家按住空格。根据后续职业选择的不同，此处呈现不同特效：

- 若玩家偏向驭灵师：一只淡墨勾勒的灵兽虚影从角色身后扑出，将角色带离原地，落点留下墨痕。
    
- 若玩家偏向灵战士：角色前方展开一面淡金盾影，妄念之影撞上来被弹开。
    
- 若玩家偏向灵术师：角色化为一道青紫光，向前位移，路径留下元素残焰。
    

> **注**：此处为无责任演示，不锁定职业，仅让玩家感受三种操作差异。

**光圈山海师**：  
"身法只是表象，真正的差异，在于你如何与万物缔结契约。"

## 2.4 职业抉择

【演出】梦境空间开始轻微震动，远处的山水剪影出现裂痕，有细碎的墨块从天空剥落，露出后面漆黑的虚空。

**光圈山海师**：  
"梦境要塌了。但在你醒来之前，你必须做出选择。"

**光圈山海师**：  
"你愿以何种方式行走山海？"

【演出】光圈分裂为三团较小的光晕，分别呈现三种颜色，悬浮在角色面前，呈品字形排列：

- 左侧：青色光晕，内部有一支灵笔虚影缓缓旋转（驭灵师）
    
- 中间：赤色光晕，内部有一柄灵刃虚影发出低鸣（灵战士）
    
- 右侧：紫色光晕，内部有一颗灵珠虚影吞吐紫芒（灵术师）
    

【系统提示】

plain

```plain
[提示] 靠近并点击选择你的职业
```

**光圈山海师**（玩家靠近青色时，光晕明亮，其余两团暗淡）：  
"以灵为媒，御兽为战。你愿成为驭灵师，与灵兽共绘山河吗？"

**光圈山海师**（玩家靠近赤色时）：  
"以身为刃，与兽同契。你愿成为灵战士，在血火中锤炼契约吗？"

**光圈山海师**（玩家靠近紫色时）：  
"以念为法，元素为兵。你愿成为灵术师，借天地之力书写灵章吗？"

【演出】玩家选择后，另外两团光晕如被风吹散的火星，缓缓熄灭。选中光晕飞入角色体内，角色剪影开始具象化——服装、武器轮廓、发色依次浮现。武器虚影凝实，落入角色手中。

**光圈山海师**：  
"很好。契约之道，从此刻起，刻入你的灵根。"

## 2.5 契约真解（捕捉机制深度教学）

【演出】光圈山海师飘到场地中央，地面升起一座圆形石台。台上悬浮着四样物品，缓缓旋转：一颗发光的「灵种」、一块刻有符文的「契石」、一小堆散发着不同气息的「灵材」、以及一卷展开的「竹简」。

**光圈山海师**：  
"接下来，是山海师最重要的功课——'缔结契约'。"

**光圈山海师**：  
"在山海界，万物皆有灵性。但并非所有灵性都愿意臣服。强行征服，只会得到一具空壳。"

【演出】光圈飘到灵种上方，灵种缓缓旋转，表面符文如呼吸般明灭。

**光圈山海师**：  
"这是'灵种'，万物之灵的雏形。现在，我要教你真正的'捕捉'之法。"

【演出】光圈分裂出一缕光线，在虚空中勾勒出几行发光的文字。文字以卷轴形式展开，不破坏沉浸感。

**光圈山海师**：  
"第一，'时机'。"

**光圈山海师**：  
"当你面对一只野生灵兽时，它不会无限期等待你的善意。从战斗开始，你只有**三十息**（30秒）的时间完成契约。超时，灵兽便会挣脱逃走，甚至可能反扑。"

【系统提示】（卷轴文字高亮）

plain

```plain

```

**光圈山海师**：  
"第二，'概率'。"

**光圈山海师**：  
"契约的成功率，取决于你与灵兽的'契合'。最基础的概率，因灵兽的'品质'而异。"

**光圈山海师**：  
"凡兽常见，契约易成；上古异兽罕见，契约难如登天。"

【系统提示】

plain


**光圈山海师**：  
"比如这只灵种属'冰月'之性，若你献上'寒潭露'或'月光草'，它便会觉得你懂它，心门敞开。"

**光圈山海师**：  
"但记住，越是稀有的灵兽，对'贡品'的抗性越强。你献上百般珍宝，上古异兽也只肯吸收其中半数。"

【系统提示】

plain

```plain
[捕捉规则] 加成效率：N/R=100% / SR=90% / SSR=70% / UR=50%
```

**光圈山海师**：  
"第三，'耐心'。"

**光圈山海师**：  
"同一只灵兽，你最多可以尝试**三次**契约。三次皆败，它的心门便会彻底关闭，进入'警觉'状态。至少**二十四时辰**（24小时游戏内时间）内，你无法再接近它。"

**光圈山海师**：
