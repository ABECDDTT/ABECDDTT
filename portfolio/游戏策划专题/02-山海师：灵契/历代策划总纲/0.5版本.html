一、游戏概述

游戏名称：《山海师：灵契》（暂定）

游戏类型：2D 仙侠灵怪收集 / 剧情冒险 / 单机 ARPG

目标受众：青少年（13岁以上），偏爱国风水墨、仙侠神话、宠物养成与剧情探索的玩家

游戏平台：PC端（Steam / WeGame），后续视情况移植手机端

核心口号：绘山河万象，契万物之灵。

核心体验：以"玄学随机开局"制造独一无二的身份认同，以"本命羁绊"建立深度情感链接，以"水墨山海"构建沉浸东方幻境，以"万物可进化"满足收集与养成的终极成就感。

二、玄学生成系统：命格标签库

2.1 系统逻辑

玩家操作：开局时，玩家在一个竹简界面上随意填写一段背景描述（0~500字，可认真填写，也可胡编乱造）。

系统解析：1）关键词提取：系统通过关键词匹配，从玩家输入中提取意向方向。2）定向抽取：根据提取到的方向，从对应标签池中抽取0~3个标签。3）随机补全：若解析出的标签不足5个，剩余标签从全库随机抽取补足至5个。4）空白/乱输处理：若玩家完全空白或输入无意义字符，则5个标签全部从全库随机抽取，彻底"听天由命"。5）唯一性规则：5个标签互不相同，不可重复。

标签作用：不影响初始基础属性（全属性固定为10）。仅影响：与特定灵兽的签约契合度；部分标签组合可触发隐藏彩蛋效果；某些隐藏职业的解锁前置条件。

2.2 标签库总览（五大方向）

方向一：命格星宿（孤星、破军、贪狼、紫微、天相、七杀、禄存）—— 影响契合度与战斗风格。

方向二：五行灵根（金灵、木灵、水灵、火灵、土灵、混元、阴阳）—— 影响元素亲和。

方向三：血脉体质（龙血、凤裔、巫族、妖瞳、灵骨、凡体、魂异）—— 影响特定种族签约。

方向四：因果经历（轮回者、背誓者、守墓人、流浪者、亡国遗孤、药人）—— 影响隐藏剧情。

方向五：道心倾向（狂战、诡道、医仙、机关、驭兽、符箓、剑心）—— 影响职业适配。

通用标签（无方向）：吃货、夜行、嗜睡、洁癖、话痨——纯随机补全池。

三、美术风格与技术实现

3.1 美术基调：写意水墨风

核心追求：摒弃精细线稿，追求形散神聚的泼墨感。场景与灵兽采用大面积留白、宣纸泛黄底色、青绿与水墨色的晕染交融。

美术生产管线：使用LiblibAI（云端SD）等工具生成概念设计图与立绘，后续通过Godot引擎制作2D骨骼动画。

3.2 UI设计语言

契合水墨风，采用竹简、卷轴、石板、印章、泼墨字体的设计语言。

3.3 技术栈

引擎：Godot 4（GDScript），低配置友好。AI辅助：Trae/Cursor中文指令生成基础代码。

四、世界观与剧情设计

4.1 宏观背景

山海界：上古《山海经》中记载的奇异世界，内有数十个国家与地域。

天道平衡：天地有阴阳，人类恶念会凝聚成"魔气"，复苏四大凶兽（穷奇、梼杌、混沌、饕餮）。神仙不可降世干预，只能将赐福化作"仙缘"散落人间。

山海师：凡人获得仙缘赐福，可在梦境中进入山海界，与异兽签订契约，维护两界平衡。

4.2 剧情特色：多线叙事与恶念值系统

主线：阻止四凶兽复苏，周游各国寻找平息"魔气"的方法。

国家剧情线：每个国家有独立故事与矛盾。玩家选择导致该国"恶念值"变化，直接决定战斗难易度及后续剧情走向。

恶念值高：魔气浓郁，野生灵兽更具攻击性，BOSS战难度提升，但掉落稀有灵材。

恶念值低：风调雨顺，可签约特殊"祥和形态"灵兽，解锁隐藏剧情与和平结局。

五、核心玩法系统

5.1 契约与灵兽系统

签约方式：野外遇到异兽，提供对应"山海灵材"作为贡品供奉。贡品契合度 + 命格标签契合度 = 最终签约成功率。

宠物成长：不独立练级，战力直接与主角当前基础属性挂钩。新宠物签约后，在现实时间2小时内平滑成长到当前上限。

全员进化：所有初始弱小的灵兽，均可通过特定进化材料与命格条件，进化成终极形态（神兽）。

5.2 职业系统与战斗

【驭灵师】武器：灵笔/符箓。定位：中距离控场，强化灵兽技能。

【灵战士】武器：灵刃/兽爪臂铠。定位：近身高频输出，与灵兽夹击。

【灵术师】武器：灵珠/兽骨法器。定位：远程AOE，元素转化。

5.3 战斗操作框架（2D ARPG）

5.4 心魔试炼（更换本命的残酷代价）

触发：玩家强行解除唯一的"本命契约"。

虚弱惩罚：立刻进入"背誓者"7天虚弱期（游戏内时间），期间全属性大幅下降（-50%），无法签订新本命。

破局方法：挑战"心魔试炼"副本。

胜利（无奖励）：立刻解除7天虚弱期。随后进入3小时（现实时间）倒计时。倒计时结束后，主角当前等级强行减半（向下取整）。无奖励、不增加属性上限，只有冰冷的代价。

失败：无额外惩罚，继续处于虚弱期，等待结束或恢复状态后重新挑战。

硬等7天：虚弱期结束后自动解除，无等级惩罚。

5.5 转职系统

转职与心魔完全分开。任何时候转职，直接扣除当前50%经验值。无虚弱期、无战斗，纯机械扣除，防止玩家频繁无脑切流派。

6.2 灵材循环设计

签约供奉：遇到野生异兽时，根据其喜好投喂对应灵材（火系喜金石/异兽血，木系喜草木），提升签约概率（基础20%，每份契合灵材+10%，上限80%）。

日常消耗：灵兽受伤后需灵材恢复（非战斗内）；维持好感度需定期投喂喜爱灵材。

进化消耗：核心消耗出口，确保玩家持续有收集动力。

交易/转化：多余灵材可在"归墟集市"按3:1比例兑换为其他类型，防止卡关。

灵材炼制：低级灵材可在炼丹炉合成高级灵材（如3火精石+1异兽血=1三昧真火石）。

6.3 进化路线模板

路线A：玄火蛇 → 赤焰蛟 → 九霄烛龙（火/灵术师最佳搭档）

路线B：绒绒兔 → 月影灵兔 → 太阴玉兔（冰/月/驭灵师最佳搭档）

路线C：铁骨虎 → 裂山虎王 → 西方白虎（金/灵战士最佳搭档）

6.4 进化机制补充

平滑过渡：进化不重置等级，新形态在2小时内平滑成长到当前上限（与签约机制一致）。

形态回溯：已进化的灵兽可在"灵契回溯"中切换为任意过往形态（仅外观与技能变化，属性保持终极形态），满足玩家对"初心"的情感需求。

真爱无敌验证：上述三条路线的初始形态均为"路边宠"，但终极形态均为顶级神兽，确保玩家情感投入有回报。

七、二十国剧情线

7.1 青丘国：狐影迷城·月落之祸

国家风貌：山巅云海，悬空木阁，千年桃树永落不停。天际悬一轮巨大"虚月"——狐族祖灵凝聚的幻象。境内多"迷障"，非妖瞳或狐族灵兽不可看破。

内部冲突：狐族圣女继承仪式被影狐派系下咒，虚月吸收生灵生命力。影狐百年前遭人类猎户捕杀，怨念被混沌气息污染。

关键灵材：青丘蔓（绒绒兔进化必需；可编织迷障披风进入羽民国风暴眼）；狐祖之泪（九尾幻狐终极进化必需，需在巫咸国净魂池净化）；虚月碎片（可抵消一次心魔惩罚，或在女子国激活倒影世界）。

特殊异兽：绒绒兔→月影灵兔→太阴玉兔；影狐（调和路线专属，暗/幻双属性）；九尾幻狐（青丘任意狐类终极进化）。

跨国线索：→巫咸国（污损狐祖之泪需净化）；→羽民国（迷障深处藏风灵通道，需羽民国风灵羽激活）；→大人国（镇压路线影狐残党逃往大人国地下竞技场）。

抉择点：镇压路线（恶念+30，影狐灭族，BOSS堕影狐王）；调和路线（恶念-20，解锁影狐签约，BOSS混沌残影）；放任路线（恶念+50，青丘毁灭，获虚月碎片）。

7.2 厌火国：焦土试炼·旱魃之殇

国家风貌：终年无雨，地表龟裂，岩浆流淌。居民厌火民居火晶树洞内。远处火山口悬浮旱魃石棺。

内部冲突：旱魃石棺异动，温度骤升，火晶树枯萎。大祭司主张献祭外来者；少主主张掘棺直面。真相：旱魃是上古山海师，以执念封印四凶兽残魂。

关键灵材：火精石（玄火蛇进化必需；可融化黑齿国万年玄冰）；三昧真火石（女子国子母河畔点燃不灭篝火，召唤隐藏异兽）；旱魃骨片（巫咸国占卜可预知国家恶念值走向）。

特殊异兽：玄火蛇→赤焰蛟→九霄烛龙；旱魃（破棺路线唯一，火土双属性，终极形态女魃）；火晶蝶（隐藏，光/火辅助）。

跨国线索：→黑齿国（地下岩浆河与毒龙潭相连，火精石融化玄冰发现岩浆通道）；→轩辕国（加固路线获山海守护者命格，触发黄帝遗脉对话）；→大人国（竞技场冠军持有炎魔臂铠，归还少主可提前解除热浪区域）。

抉择点：献祭路线（恶念+40，厌火国封闭，BOSS被激怒的旱魃残魂）；破棺路线（恶念-30，获旱魃签约，加速四凶兽复苏倒计时）；加固路线（剧情强制7天虚弱，获山海守护者标签）。

7.3 大人国：力之极境·泰坦之傲

国家风貌：巨人之国，建筑如山岳，一扇门十丈高。境内遍布巨型兵器与远古战兽骸骨。中央为不周竞技场，以力量为唯一真理。

内部冲突：极端派碎山者主张碾碎一切弱小生灵，认为只有绝对力量才能阻止四凶兽。他们的恶念吸引了梼杌残魂寄生在竞技场地下。

关键灵材：泰坦精钢（铁骨虎进化必需；羽民国可锻造风钢翼）；战魂结晶（灵战士转职战狂必需；巫咸国可复活一次阵亡灵兽）；巨人指骨（小人国可作为桥梁或杠杆，解锁微观洞穴）。

特殊异兽：铁骨虎→裂山虎王→西方白虎；山岳巨猿（土属性肉盾，终极形态通臂猿猴）；竞技场幽魂（隐藏，不用本命契约连胜15场后出现）。

跨国线索：→小人国（共生关系，碎山者破坏平衡）；→青丘国（镇压路线影狐残党搅局）；→厌火国（冠军持有炎魔臂铠，归还少主可解除热浪）。

抉择点：支持碎山者（恶念+40，小人国关闭，获碎山者徽章商店半价）；调和路线（恶念-20，开启联合商路，解锁共生藤）；独力破魂（恶念不变，获独夫标签）。

7.4 小人国：微观乾坤·芥子须弥

国家风貌：国民身高三寸，居蘑菇屋、螺壳殿中。境内草木对常人而言如参天巨树，一滴露水即为一潭。需服用缩形草或携带微观灵兽才能进入核心区域。

内部冲突：小人国世代为大人国维护微观裂缝，但碎山者震地导致微观世界崩裂。迁离派想逃离，修复派想坚守。迁离派绝望吸引了饕餮残魂。

关键灵材：缩形草（进入核心区域必需；巫咸国可炼制神行丹）；须弥露珠（草木类灵兽终极进化通用；女子国子母河滴入可治愈恶念）；蚁后玉髓（黑齿国可作为解毒剂原料）。

特殊异兽：寻宝鼠（探测隐藏宝箱）；微观龙（修复派任务专属，终极形态芥子神龙）；共生藤（调和路线专属，草木/辅助双属性）。

跨国线索：→大人国（调和路线开放根系网络捷径）；→青丘国（迷障显微镜可看破最深幻境）；→羽民国（工匠修复风灵翼，开放罡风层）。

抉择点：协助迁离（恶念+30，大人国塌陷，羽民国获云下居民）；协助修复（恶念-20，获微观之眼）；袖手旁观（恶念+10，黑市倒卖缩形草）。

7.5 羽民国：罡风之域·云巢悬天

国家风貌：国民背生双翼或乘巨鸟，居浮空岛与云巢之中。地面为无尽云海，坠落即死。境内多罡风，可撕裂非飞行单位。

内部冲突：羽民国掌握风灵通道，但近年来通道不稳定。保守派天羽宗主张关闭通道；革新派云游者主张修复。真相：通道不稳定是因为青丘国虚月异变导致天地灵气失衡，国主已被穷奇残魂蛊惑。

关键灵材：风灵羽（激活青丘国风灵通道必需；飞行类灵兽进化通用）；罡风结晶（大人国可锻造轻型护甲，闪避耐力消耗-30%）；云巢树脂（厌火国可涂抹火晶树延缓枯萎）。

特殊异兽：云雀（风属性，预警危险）；大鹏幼鸟（从蛋培养，终极形态金翅大鹏）；风灵（隐藏，罡风层坚持60秒，元素类无实体）。

跨国线索：→青丘国（通道直连云巅，虚月未修复则通道喷魔气）；→小人国（迁离派抵达后加固云巢，开放旧云巢遗迹）；→黑齿国（国主被穷奇蛊惑线索可在黑齿国毒龙神殿找到穷奇毒囊共鸣）。

抉择点：揭露国主（恶念-30，开放风灵通道，获云游者之翼）；协助隐瞒（恶念+40，获金翅大鹏蛋，通道20%概率虚空乱流）；修复通道（恶念不变，获风灵工程师标签）。

7.6 巫咸国：魂归之所·卜筮天机

国家风貌：巫师之国，境内遍布祭坛、骨塔、净魂池。天空常年呈现诡异的紫红色，因国中燃烧魂火。国民以占卜为生。

内部冲突：巫咸国掌握轮回镜，但近来镜面龟裂，映照出的未来全是灭世画面。大巫师团主张活人献祭修补；少巫主张寻找龟裂真正原因。真相：轮回镜在预警四凶兽封印多处松动，大巫师团被混沌残魂寄生。

关键灵材：净魂池水（净化青丘国污损狐祖之泪；可洗去灵兽堕落状态）；占卜龟甲（一次性预知任意国家恶念值走向；轩辕国可兑换黄帝密卷）；魂火余烬（进化亡灵类灵兽必需；厌火国可点燃冷火进入坍塌洞穴）。

9.1 竹简·命格生成界面

顶部：水墨标题"命格天定"。中部：竹简卷轴输入框（玩家填写背景描述，0-500字）。底部："解签"按钮（点击后竹简缓缓展开，5个标签以朱砂印章形式依次盖下，伴随水墨晕染特效）。右侧：标签说明悬浮窗（鼠标悬停显示该标签的效果与契合灵兽）。

9.2 卷轴·山海地图

整体为展开的泛黄卷轴，各国以水墨轮廓呈现。已访问国家：彩色水墨（青丘国桃红、厌火国赤红等）。未访问国家：淡墨轮廓。国家图标：该国代表性灵兽剪影。连线：风灵通道以金色虚线连接各国。恶念值可视化：国家轮廓边缘有红色晕染（恶念高）或金色光晕（恶念低）。点击国家：卷轴局部放大，显示该国任务进度与可签约灵兽列表。

9.3 石板·设置界面

背景为深色石板，文字以篆刻形式呈现。左侧：设置分类列表（画面/音效/操作/存档）。右侧：具体选项，以"刻痕"形式呈现滑块。底部："恢复默认"按钮（以橡皮擦除特效呈现）。

9.4 灵兽契约界面

中央：异兽立绘（水墨动态，呼吸效果）。左侧：异兽属性面板（以竹简形式展开）。右侧：贡品供奉栏（3个格子，拖拽灵材放入）。底部："缔约"按钮（点击后进入契约动画：玩家与异兽之间出现灵气连线，成功则盖下朱红大印，失败则连线断裂，异兽逃跑或进入战斗）。

9.5 战斗HUD

左上角：主角血条（红色水墨）+ 灵力条（蓝色水墨）。左下角：技能栏（Q/E/R以符文图标呈现，CD时图标灰度化并覆盖水墨滴落特效）。右上角：当前出战灵兽水墨头像 + 灵兽血条（绿色）。右下角：灵材快捷栏（1-4数字键对应）。屏幕中央下方：连段计数器（每完成一段普攻，出现水墨数字"壹/贰/叁"，第三段触发"契灵追击"时全屏水墨爆开）。

9.6 背包·乾坤袋

背景为布袋内部（棉麻纹理）。物品以"悬浮卡牌"形式呈现，卡牌边缘有对应灵材类型的颜色标识（草木绿、金石灰、异兽血红、灵魂结晶紫）。拖拽物品至炼丹炉区域可合成。底部："整理"按钮（点击后物品自动分类排列，伴随卡牌洗牌动画）。

9.7 心魔试炼界面

进入时全屏变黑，仅有玩家与心魔BOSS的剪影对峙（镜像对称）。BOSS轮廓由玩家当前装备与灵兽特征扭曲而成。血条以"裂痕"形式呈现于屏幕顶部。无技能栏，仅保留普攻与闪避（象征"面对自我"的纯粹战斗）。击败后：镜面碎裂特效，回到正常界面。

9.8 进化·蜕凡池

中央：圆形水池（水墨涟漪动态效果）。左侧：当前灵兽形态立绘。右侧：进化后形态剪影（未满足条件时为淡墨，满足后逐渐清晰）。底部：材料需求列表（已收集材料显示彩色，未收集显示灰度）。"进化"按钮：点击后灵兽跃入水池，水面泛起光芒，2小时倒计时以水墨滴漏形式呈现。

9.9 归墟集市

背景为热闹的水墨街市，NPC以剪影形式走动。左侧：玩家出售栏。右侧：NPC收购/出售栏。中间：价格对比表（以算盘形式呈现）。交易成功时：铜钱碰撞音效 + 水墨"成交"二字浮现。

9.10 墨碑·存档点

场景中的实体：一块立着的墨碑（可交互）。交互后：卷轴展开，显示存档槽位（以"卷轴编号"形式）。存档时：毛笔书写动画，墨迹未干效果。读档时：墨迹倒流，时间回溯感。
