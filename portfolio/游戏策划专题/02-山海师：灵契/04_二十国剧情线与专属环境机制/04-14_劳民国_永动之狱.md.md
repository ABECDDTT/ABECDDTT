# 六、专属环境机制：【永动齿轮伤害/无休NPC冲撞系统】
| 机制名 | 永动齿轮·无休冲撞 |
|--------|----------|
| 触发区域 | 劳民国100%区域（工厂内部、水车周边、永动核心矿区、运输轨道、认命派/解脱派领地） |
| 视觉效果 | 天空永远是灰蒙蒙的黎明，无黑夜；到处都是自动运转的齿轮、永不停止的水车、持续劳作的NPC；地面有轨道与传动轴不断运转 |
| 负面效果 | ① 永动齿轮：工厂区域内齿轮裸露，触碰即受到"碾压伤害"（生命-15%+击退）；② 无休NPC冲撞：劳民因永动诅咒无法停止移动，会直线冲撞路径上的一切（包括玩家），被撞到后眩晕2秒+生命-5%；③ 水车区域：靠近大型水车时受到"水流冲击"（移速-50%，有概率被卷入水车受到连续伤害）；④ 永动诅咒：玩家在劳民国停留超过10分钟（现实时间），获得"倦怠"DEBUFF（全属性-5%，可叠加3层，离开劳民国后每5分钟恢复1层） |
| 应对方式 | ① 携带机关牛/机关兽·狻猊：齿轮伤害免疫，且可短暂停止局部齿轮运转（开辟安全路径）；② 服用神行丹（MAT-B10+MAT-C07）：劳民国国民识别为"同类"，停止冲撞玩家；③ 装备永动核心护符（MAT-S19×1）：齿轮伤害-50%，且可命令灵兽进入"狂暴劳作"（采集效率+50%，但好感度下降）；④ 解除诅咒路线完成后：永动停止，所有负面效果消失，天空恢复昼夜交替 |
| 深度交互 | 永动核心是机关类灵兽进化与自动战斗傀儡的关键材料；三首国三世镜中存储劳民国诅咒的"前世记忆"（劳民国国民本是黄帝战士）；轩辕国封魔台修复后劳民国诅咒自动解除（回收黄帝战意）；诅咒解除瞬间，时间蠕虫从停止的水车中出现 |
| 关联参数 | 若劳民国恶念值 > 40，齿轮运转速度+50%，冲撞伤害提升至-10%，且"倦怠"叠加速度翻倍；若窃取核心路线完成，劳民国变为死国，齿轮生锈停止，但地图荒芜无产出；若维持永动路线完成，永动核心产量翻倍，但解脱派NPC永久敌对 |
