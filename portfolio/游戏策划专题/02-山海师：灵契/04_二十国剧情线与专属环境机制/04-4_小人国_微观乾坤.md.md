# 六、专属环境机制：【微观缩放系统】
| 机制名 | 微观缩放 |
|--------|----------|
| 触发区域 | 小人国100%区域（对常人而言所有物体均为巨物） |
| 视觉效果 | 玩家视角下草木如参天巨树、水滴如深潭、螺壳如宫殿；非缩形状态下无法进入核心区域 |
| 负面效果 | ① 未缩形：无法穿过"微观裂缝"（实际为正常大小的门）；② 缩形状态下：移动速度-20%（相对距离变长）；③ 缩形草时效30分钟，超时自动恢复，若处于微观洞穴内则每秒受到"挤压伤害"×2% |
| 应对方式 | ① 服用缩形草（MAT-C07）：进入微观状态30分钟；② 携带微观龙/共生藤：缩形状态下移速惩罚取消；③ 装备迷障显微镜（青丘国图纸+小人国工匠制作）：可看破微观幻境，发现隐藏路径 |
| 深度交互 | 微观洞穴深处藏有"亚微观深渊"入口（需须弥晶扩容后进入）；微观裂缝与大人国震地波直接关联，大人国恶念值>40时裂缝扩大，小人国出现新区域"崩塌深渊" |
| 关联参数 | 若小人国恶念值 > 30，缩形草效果降至15分钟；迁离路线完成后羽民国云巢新增"云下居民"区域 |
