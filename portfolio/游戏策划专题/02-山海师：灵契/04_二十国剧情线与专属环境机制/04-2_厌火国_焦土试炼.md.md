# 六、专属环境机制：【热浪系统】
| 机制名 | 热浪侵袭 |
|--------|----------|
| 触发区域 | 厌火国80%区域（除火晶树洞内部） |
| 视觉效果 | 空气扭曲热浪、地面龟裂发光、远处火山口间歇喷发 |
| 负面效果 | ① 非火属性/无抗热装备玩家：每10秒扣除最大生命值2%（真实伤害，无视防御）；② 火属性灵兽：全属性+10%；③ 水属性灵兽：全属性-20%，移动速度-30% |
| 应对方式 | ① 服用寒冰丹（冰魄×2+净魂池水×1）：永久免疫热浪；② 躲入火晶树洞：安全区，可恢复；③ 携带旱魃/火晶蝶：热浪伤害-50% |
| 深度交互 | 火山口区域热浪伤害翻倍（每10秒4%），但火精石产出效率+50%；旱魃石棺周边有"热浪脉冲"（每30秒一次大范围击退） |
| 关联参数 | 若厌火国恶念值 > 40，热浪伤害提升至每10秒5%，火晶树洞开始枯萎（安全区缩小） |
