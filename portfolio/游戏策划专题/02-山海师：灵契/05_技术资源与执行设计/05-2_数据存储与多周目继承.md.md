# 一、存档数据结构总表
| 数据块 | 字段名 | 类型 | 大小估算 | 说明 |
|--------|--------|------|----------|------|
| 玩家基础 | player_name | string | 32B | 玩家昵称 |
| 玩家基础 | player_level | int16 | 2B | 当前等级 |
| 玩家基础 | player_exp | int32 | 4B | 当前经验值 |
| 玩家基础 | current_class | uint8 | 1B | 当前职业ID（0=驭灵师,1=灵战士,2=灵术师,3-8=隐藏职业） |
| 玩家基础 | oath_break_count | uint8 | 1B | 累计解约次数 |
| 命格系统 | fate_tags[5] | uint16[5] | 10B | 5个命格标签ID |
| 命格系统 | fate_input_text | string | 512B | 玩家原始输入文本 |
| 契约系统 | beast_slots[5] | struct[5] | ~200B | 平等/伙伴契约槽位（ID,等级,形态,好感度） |
| 契约系统 | oath_beast | struct | ~40B | 本命契约灵兽（独立存储） |
| 契约系统 | temp_beasts | struct[] | 动态 | 临时契约列表（战斗外清空，可选存） |
| 背包系统 | inventory | struct[] | ~10KB | 灵材ID+数量（上限200格） |
| 剧情进度 | global_evil[20] | int8[20] | 20B | 20国恶念值（-100~100，用int8足够） |
| 剧情进度 | nation_route[20] | uint8[20] | 20B | 各国路线选择（0=未选,1=路线A,2=路线B...） |
| 剧情进度 | beast_wake | float | 4B | 四凶兽复苏进度 |
| 剧情进度 | key_items | uint32 | 4B | 关键道具位掩码（32位可标记32个关键道具） |
| 剧情进度 | hidden_profession_unlock | uint8 | 1B | 隐藏职业解锁位掩码 |
| 剧情进度 | week_count | uint16 | 2B | 游戏内经过周数（用于女子国3年毁灭倒计时） |
| 多周目 | inheritance_points | int32 | 4B | 继承点数（用于多周目商店） |
| 多周目 | cleared_endings | uint8 | 1B | 已通关结局位掩码 |
| 多周目 | beast_pedia | uint64[4] | 32B | 图鉴收集位掩码（256只灵兽） |
| 设置 | graphics_settings | struct | ~20B | 分辨率、画质等级、水墨渲染强度 |
| 设置 | audio_settings | struct | ~10B | 主音量、BGM、SFX、语音 |

# 二、存档槽位规划
| 槽位 | 用途 | 自动保存时机 |
|------|------|--------------|
| 存档0 | 自动存档 | 进入新国家、完成主线任务、战斗胜利后 |
| 存档1-5 | 手动存档 | 玩家手动触发 |
| 存档S | 系统备份（退出前） | 游戏正常退出时 |
| 存档T | 临时战斗存档 | 进入BOSS战前（死亡后可读档） |

# 三、多周目继承规则
| 继承项目 | 第一周目 | 第二周目 | 第三周目+ | 备注 |
|----------|----------|----------|-----------|------|
| 玩家等级 | 不继承 | 继承50%（向下取整） | 继承80% | 防止碾压 |
| 灵兽等级 | 不继承 | 继承初始形态，等级=玩家等级 | 同左 | 保留进化路线记忆 |
| 本命契约 | 不继承 | 清空，需重新签订 | 同左 | 心魔试炼次数清零 |
| 命格标签 | 不继承 | 重新生成 | 重新生成 | 保持每局独特性 |
| 背包灵材 | 不继承 | 继承草木类×10份随机 | 继承全部非灵魂结晶 | 降低前期重复劳动 |
| 灵魂结晶 | 不继承 | 不继承 | 不继承 | 控制终极进化节奏 |
| 恶念值 | 不继承 | 初始值=上周目最终值×20% | 初始值=上周目最终值×50% | 多周目世界越来越"熟悉" |
| 隐藏职业解锁 | 永久继承 | 永久继承 | 永久继承 | 账号级解锁 |
| 图鉴收集 | 永久继承 | 永久继承 | 永久继承 | 账号级解锁 |
| 结局收集 | 永久继承 | 永久继承 | 永久继承 | 用于真结局解锁条件 |
| 继承点数 | 根据上周目成就计算 | 累加 | 累加 | 用于多周目商店购买 |

# 五、云存档与本地存档策略
| 平台 | 本地存档路径 | 云存档 | 冲突处理 |
