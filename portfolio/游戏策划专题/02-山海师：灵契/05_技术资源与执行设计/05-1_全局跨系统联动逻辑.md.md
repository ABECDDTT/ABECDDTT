# 三、联动规则执行优先级
| 优先级 | 规则类型 | 执行顺序 |
|--------|----------|----------|
| P0 | 国家毁灭/关闭 | 最先执行（修改GLOBAL_NATION_OPEN） |
| P1 | 四凶兽复苏进度 | 其次执行（修改GLOBAL_BEAST_WAKE） |
| P2 | 全局属性/BUFF | 再次执行（修改玩家状态） |
| P3 | 经济/价格变动 | 最后执行（修改GLOBAL_MARKET_MOD等） |

# 四、事件广播机制
| 事件名 | 广播时机 | 订阅系统 | 处理逻辑 |
|--------|----------|----------|----------|
| EVIL_CHANGED | 任意国家恶念值变动 | 战斗系统、环境系统、UI系统 | 重新计算该区域怪物攻击性与环境效果 |
| NATION_CLOSED | GLOBAL_NATION_OPEN位变化 | 地图系统、任务系统 | 关闭对应国家入口，更新任务指引 |
| BEAST_WAKE_UP | GLOBAL_BEAST_WAKE达到25/50/75/100 | 剧情系统、战斗系统 | 触发四凶兽阶段性剧情/解锁新BOSS |
| MARKET_UPDATED | GLOBAL_MARKET_MOD变化 | 商店系统、UI系统 | 全局刷新所有商店价格显示 |
