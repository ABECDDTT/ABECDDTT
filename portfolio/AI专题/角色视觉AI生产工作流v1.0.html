角色视觉 AI 生产工作流 v1.0

适用：AI 陪伴类产品角色 / 场景 / 演出素材探索　｜　工具：LiblibAI / Stable Diffusion　｜　设计：杨长辉

「用 AI 出图」不是目的，「出的图能直接用、跨端一致、情绪可被 0.3 秒读对」才是目的。本工作流把角色视觉从一次性抽卡，变成可复用、可交接、可验收的生产线。

流程：性格参数 + 情绪态 → ① 视觉映射 → ② Prompt 模板 → ③ 一致性控制 → ④ 筛选验收 → ⑤ 结构化反馈 → 归档复用

① 视觉映射：把性格翻译成视觉语言

性格 / 情绪 视觉表达
高外向 主动姿态、肢体靠近、动作幅度大
高傲娇 眼神偏开、口是心非的微表情（嘴硬但身体靠近）
高粘人 贴身、依偎、视线跟随用户
高情绪性 表情幅度大、情绪转换明显
低落态 低垂、蜷缩、动作减少但保持在场

风格基线：圆润 Q 版，贴合 IP 原作，三端一致；表情系统 8 种基础表情 + 情绪态（开心 / 委屈 / 傲娇 / 困）。微动作原则——低幅度、高频率、随机化：幅度太大像抽搐，频率太低等于没有，完全固定会被识破为循环动画。

② Prompt 模板（六段式，可复用）

结构 = [风格锚点] + [角色主体] + [表情情绪] + [姿态微动作] + [光影氛围] + [画质参数]

示例（火花·低落态）：圆润Q版宠物角色设计，小火龙形态，橙色体表+火焰尾，表情委屈（眉毛下垂、嘴角抿起、眼睛半阖），坐在地上尾巴无力垂落、微微低头，暖色柔光、角落光晕、浅景深，干净白底、三视图对齐、高细节、8k

负向约束（通用）：写实、恐怖、多人、文字水印、肢体畸形、过度锐化、复杂背景、低分辨率、表情模糊、动作夸张

③ 一致性控制（保证「同一只宠物」）

  • 固定种子：同一角色固定 seed，仅微调情绪与姿态描述词

  • 参考图锁定：以 IP 原作或已定稿三视图作参考图，用 IP-Adapter / 图生图控制形象

  • 风格 LoRA：整套角色统一风格 LoRA，保证跨角色、跨批次风格不漂移

  • 三视图定稿：先出正 / 侧 / 背三视图定稿，再派生表情与微动作

  • 跨端统一：同一角色在游戏 / 桌宠 / 机械宠的轮廓、配色、标志性特征辨识度必须一致

④ 筛选验收（人工定稿前的强制检查）

  • □ 情绪可读：抽 10 人快速测试，须在 0.3 秒内读对情绪

  • □ 跨端一致：三端缩略图并列，辨识度统一

  • □ 表情—情绪映射无歧义：8 种基础表情不串味

  • □ 微动作幅度：低幅度、不抽搐、无循环感

  • □ 无畸形 / 无水印 / 无风格漂移

⑤ 结构化反馈模板（给美术与技术，必须可直接执行）

反馈 = 问题（现象）→ 目标（体验标准）→ 方案（具体改法）→ 验证（怎么算改好）

视觉样例｜问题：桌宠在夜间模式下过暗，看不清表情。→ 目标：月光模式下仍需 0.3 秒内读对情绪。→ 方案：为月光模式单独调一套表情亮度曲线，仅提亮五官区域，保持整体低亮度。→ 验证：夜间模式下情绪识别正确率 ≥ 90%，用户主观「不刺眼」评分 ≥ 4.0 / 5。

⑥ 生产纪律

  • AI 出探索，人做定稿：AI 负责「给可能」，人负责「选哪个、为什么」

  • 所有 AI 生成内容先过安全护栏，再进产品或社区

  • 沉淀即资产：每次定稿回填 Prompt 与「已验证模板库」，避免重复抽卡

立场说明：本工作流中的阈值（0.3 秒、90%、4.0/5 等）为可讨论的设计目标值，非承诺指标，落地需以实测与业务实际为准。
