# 问道山海 · 修仙文字游戏

> 以《山海经》异闻为骨，修仙问道为魂 · 纯前端 HTML 实现

## 项目概述

这是一个**纯文字剧情驱动**的修仙游戏原型，基于同名策划案开发。玩家以"求道者"身份踏入被四凶兽侵蚀的山海界，在二十国异域中历练、抉择、悟道。

## 技术栈

- **HTML5** + **CSS3** + **原生 JavaScript**（ES6+）
- **零依赖**（无任何 npm 包、无构建步骤）
- **数据驱动**：所有剧情文本、命格池、职业、境界都在 `js/data/` 中以 JS 对象存储
- **存档**：localStorage 多槽位 + 全局山海绘卷收藏
- **背景**：高规格 AI 生成水墨风格场景图（已全部压缩优化）
- **当前版本**：v1.3.2（图鉴天成）

## 如何运行

### 方法一（推荐）：直接双击 index.html

`index.html` 是**单文件版**，已将全部 CSS/JS 内联，**双击即可在浏览器中运行**（file:// 协议下正常工作）。

- 无需安装任何软件、无需启动服务器
- 双击后进入**封面**，可自主选择：**【踏入山海】**（正常剧情流程）或**【快速体验·跳过教程】**（直接进入自由行动）

### 方法二：本地服务器（HTTP 访问）

项目同样支持 HTTP 服务器访问。推荐使用：

```bash
# Python 3
python -m http.server 8765

# Node.js (需安装)
npx http-server -p 8765
```

然后浏览器访问 `http://localhost:8765/`

- 正常流程：`http://localhost:8765/`
- 调试模式：`http://localhost:8765/?debug=1`（显示"跳过教程"按钮）

## 核心系统

### 1. 命格抽取算法

玩家输入 0~500 字背景描述，系统按以下流程抽取 5 枚命格：

1. **关键词匹配**：从六大方向池（星宿/五行/血脉/因果/道心/通用）的词根库扫描
2. **定向抽取**：得分最高的方向池优先抽 1 个标签（最多 3 个）
3. **随机补足**：不足 5 个时从全库随机补（含通用标签）
4. **互斥校验**：去除冲突标签（如夜行+嗜睡）
5. **唯一性校验**：5 个标签互不相同

### 2. 三教职业

- **道徒**：中距离控场 · 符箓召唤 · 主修《黄庭经》
- **禅人**：近身肉搏 · 肉身成圣 · 主修《易筋经》
- **儒生**：远程 AOE · 言灵镇邪 · 主修《浩然气》

三教并非阵营对立。游戏中可通过奇遇、抉择、秘境领悟其他教派技能。

### 3. 青丘国剧情（已实现）

主线 Q01_01~03 + 1 支线（猎户后人）+ 1 隐藏任务（墨家遗迹）+ 1 BOSS 战（堕影狐王）

**三种结局**：
- **镇压路线**（恶念+30）：协助天狐镇压影狐，无法签约影狐
- **调和路线**（恶念-20）：寻找猎户后人道歉化解怨念，习得狐灵签约权
- **放任路线**（恶念+50）：取走虚月核心离开，青丘毁灭

### 4. 文字战斗

回合制 · 双方行动以战斗日志呈现 · 关键数值变化标红/标绿/标金/标紫

技能含：普攻、技能（CD 管理）、奥义（能量槽满）、空格技、被动

## 设计哲学

> "命格先天，因果后天。一念成神，一念成魔。"

本作追求：
- **不卖数值**（承诺买断制章节 + 外观/便捷性内购）
- **剧情驱动**（每个选择都有延迟反馈，没有"正确答案"）
- **沉浸感**（背景图营造氛围、文字逐字呈现、战斗有操作感）
- **可重玩性**（多周目 + 命格继承 + 隐藏职业）
