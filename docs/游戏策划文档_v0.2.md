## 一、游戏概述

**《问道山海》** 是一款**纯文字剧情驱动**的修仙文字游戏（AVG+MUD 混合）。

- **题材**：以《山海经》异闻为骨，修仙问道为魂
- **核心循环**：剧情抉择 → 自由行动（修炼/探索/生活）→ 战斗成长 → 突破境界 → 新剧情
- **核心哲学**："命格先天，因果后天。一念成神，一念成魔。"
- **不卖数值**：买断制章节 + 外观/便捷性内购
- **载体**：单文件 HTML（双击即玩，零依赖）

### 玩家目标
以"求道者"身份踏入被四凶兽侵蚀的山海界，在**二十国异域**中历练、抉择、悟道，最终决定世界走向。

## 四、三教职业（已实现）

三教并非阵营对立，可通过奇遇/抉择领悟他教技能。

### 4.1 道徒（中距离控场·符箓召唤）
- 系数：生命0.90 / 灵力1.20 / 攻击0.95 / 防御0.85
- 主修《黄庭经》：灵力上限+20%，灵宠继承+5%
- 技能：
  - 点灵（普攻·道）叠灵痕
  - 镇魂符（金）破甲
  - 烈焰符（火）灼烧
  - 风遁符（风）减速+闪避
  - 万灵归宗（奥义·道）召唤灵宠齐攻
  - 灵兽瞬闪（位移·风）

### 4.2 禅人（近身肉搏·肉身成圣）
- 系数：生命1.15 / 灵力0.70 / 攻击1.10 / 防御1.05
- 主修《易筋经》：生命+15%，格挡窗口+0.05秒
- 技能：
  - 裂空爪（普攻·金）三段破甲
  - 金刚焚身（火）自伤换爆发
  - 铁壁震击（土）震伤+降防
  - 兽血沸腾（禅）攻速+吸血
  - 人兽同契（奥义·禅）全属性爆发
  - 铁壁格挡（格挡·土）弹反

### 4.3 儒生（远程AOE·言灵镇邪）
- 系数：生命0.80 / 灵力1.30 / 攻击1.00 / 防御0.75
- 主修《浩然气》：元素伤害+12%，言灵CD-10%
- 技能：
  - 灵弹（普攻·金）溅射
  - 砚海凝冰（水）冻结减速
  - 风雷言（风）风雷连击

## 五、命格系统（已实现）

### 5.1 抽取算法
玩家输入0~500字背景描述：
1. 从六大方向池词根库扫描关键词
2. 得分最高的方向池优先抽取（最多3个）
3. 不足5个从全库随机补足
4. 互斥校验（如夜行+嗜睡冲突）
5. 保证5枚互不相同

### 5.2 六大方向池
- **星宿**：天相（生命+5%）/七杀（攻击+8%）/廉贞（暴击+5%）/破军（CD-8%）/孤星（暴击+5%）/天机（CD-5%）/紫微（全属性+2%）/天府（防御+5%）
- **五行**：金芒（攻击+5%）/木灵（治疗+10%）/火灵（火伤+10%）/土御（防御+8%）/水柔（闪避+5%）/花青（生命+8%）
- **血脉**：麒麟（生命+8%）/玄武（防御+8%）/青龙（攻击+8%）/朱雀（火伤+10%）/龙血（吸血）
- **因果**：道运（全属性+2%）/业火（火伤+10%）/慈悲（治疗+15%）/罪孽（攻击+10%）/渡己（受击减伤）/奇缘（采集+20%）/孽缘（攻击+8%）
- **道心**：悟微（修炼+15%）/医仙（治疗+15%）/静心（CD-5%）/不争（采集+15%）/心魔（攻击+10%）/守一（防御+5%）/忘忧（全属性+2%）
- **通用**：疾行（闪避+5%）/生机（治疗+5%）/药童（采集+10%）/阴阳（异常抵抗+10%）/五行平衡（全属性+2%）/祥瑞（集运）/孤傲（攻击+5%）/破欲（异常抵抗+10%）/星辉（暴击+5%）/夜行（闪避+5%）/嗜睡（生命-5%）/残刃（攻击+10%）

### 5.3 命格加成已生效（战斗/生活）
- 攻击：atk（七杀/金芒/青龙/罪孽/心魔/残刃等）
- 防御：def（天府/土御/玄武/守一）
- 暴击：crit（廉贞/孤星/星辉）
- 闪避：dodge（水柔/疾行/夜行）
- 破甲：armorBreak
- CD缩减：cdReduce（破军/天机/静心）
- 元素伤：fire/water/metal
- 治疗：heal（木灵/慈悲/医仙/生机）
- 持续治疗：hot
- 异常抵抗：resist（阴阳/破欲）
- 修炼/采集/炼丹：cultivation/gather/refine
- 全属性：all（紫微/道运/忘忧/五行平衡）

## 六、数值体系（已实现）

### 6.1 境界与属性倍率
| 境界 | 需等级 | 属性倍率 |
|------|--------|---------|
| 炼气期 | 1 | 1.0 |
| 筑基期 | 10 | 1.3 |
| 金丹期 | 20 | 1.7 |
| 元婴期 | 35 | 2.2 |
| 化神期 | 50 | 2.8 |
| 渡劫期 | 70 | 3.5 |
| 飞升 | 90 | 5.0 |

突破需等级达标 + **心魔试炼战斗**（与玩家镜像对决），胜利才突破。

### 6.2 基础属性
- 基准：生命940 / 灵力940 / 攻击110 / 防御50（50级基准）
- `实际值 = 基准 × 职业系数 × (1 + 0.1×(lv-1)) × 命格加成`

### 6.3 伤害公式（策划案13.2）
```
实际伤害 = [(攻方攻击 × 技能威力) × 元素克制 × 连击] × 100 / (100 + 守方防御)
```
- 属性克制：克制1.3倍 / 被克0.8倍
- 连击：连续命中+5%/次，最多+30%（被闪避/受击中断）
- 暴击：基础8%+命格，1.6倍
- 元素反应：火+木=灼烧翻倍、水+火=真实伤害、火+风=借势等

### 6.4 战斗机制
- 轻回合制：玩家选技能，敌方智能AI
- 奥义能量槽：普攻+22/技能+32，受击+8，约3回合满
- BUFF/DEBUFF：灼烧/减速/破甲/缠绕/格挡弹反/吸血
- 战利品：修为+金币+灵材（胜利掉落）

### 6.5 时辰系统（自由行动）
- 每日6时辰，每项行动消耗1个
- 时辰尽后就寝进入新一日
- 每日重置，灵圃结算收获

### 6.6 灵宠
- 品质：N/R/SR
- 属性 = 玩家 × 种族系数 × 契约继承 × 进化阶段
- 契约继承：临时0.5/平等1.0/伙伴1.5/本命2.0
- 进化阶段：初始1.0/一阶1.4/终极2.2/隐藏2.6
- 培养消耗朱果：等级越高消耗越多（1级需2个，每级+1）
- 战斗中自动协战攻击/治疗

### 6.7 金币经济
- 探索拾得/战斗掉落/出售灵材获得
- 购买稀有材料/灵宠培养消耗

## 七、剧情续写规范（供其他 AI）

### 7.1 场景数据结构
所有剧情场景定义在 `js/data/nations/<国名>.js`，结构如下：
```js
{
  id: '场景唯一ID',       // 如 'q01_01'
  title: '章节标题',
  bg: BG.场景背景,          // 引用 BG 对象里的背景图
  text: '剧情文本...',       // 支持 [highlight]关键词[/highlight] 高亮
  options: [
    {
      label: '选项文字',
      tag: '可选标签(自由/主线/机缘...)',
      require: { mingshen:'命格id', attribute:'属性', lv:5 },  // 可选，条件不满足灰显
      evilDelta: 10,          // 可选，选择后恶念值变化
      completed: 'Q01_MAIN_DONE',  // 可选，标记完成的剧情ID
      onChoose: (player)=>{}, // 可选，选择时执行的自定义逻辑
      next: '下一个场景ID'     // 跳转目标
    }
  ]
}
```

### 7.2 剧情写作要点
1. **沉浸感**：每个场景300-800字，重氛围与心理描写
2. **抉择**：关键节点给2-4个选项，**没有绝对正确答案**，每个选择有延迟反馈（恶念/关系/结局）
3. **善恶线**：抉择影响 `恶念值(evil)`，恶念高触发凶险机缘，低触发祥和
4. **三结局原则**：每个国家应有镇压/调和/放任至少三种走向

### 7.3 注册新场景
新国家场景需在文件末尾 `global.<国家名>_SCENES = {...}` 注册，并在 `js/app.js` 的 runScene 中（或通过场景 `battle` 配置）调度。

### 7.4 命格触发隐藏内容
可在场景 `require.mingshen` 指定命格id（如 `wenchang/qinjian/shenzhou` 触发墨家遗迹），体现"命格决定奇遇"。

## 八、已实现剧情（青丘国 Q01）

### 主线 Q01_01~03
- **Q01_01 桃林迷踪**：求道者醒来于桃林，遭遇虚月异变
- **Q01_02 狐影初现**：接引使者，圣女赐灵圃与令牌，得绒绒兔灵宠
- **Q01_03 迷障深处**：调查影狐，决战堕影狐王·墨姬

### 支线与隐藏
- **Q01_B1 猎户后人**：化解百年前猎户与影狐的恩怨
- **Q01_H1 墨家遗迹**：隐藏任务，需机关命格触发

### 三种结局
- **镇压**（恶念+30）：协助天狐镇压影狐，无法签约影狐
- **调和**（恶念-20）：化解怨念，习得狐灵签约权
- **放任**（恶念+50）：取走虚月碎片，青丘永夜
