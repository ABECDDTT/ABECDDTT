# 问道山海 · 文档关系与移植说明

> 说明本项目各文档的层级关系，以及将游戏复制到另一台电脑所需的最小文件清单。

---

## 一、文档层级关系

```
【策划案草案 v0.1】            ← 设计构想源（桌面 docx，偏世界观/系统设计）
   │
   ▼ 落地为可执行游戏
【游戏策划文档 v0.2】          ← 当前游戏实际实现的一手文档（docs/）
   │                              · 完整系统、数值、剧情框架
   │                              · 供其他 AI 续写剧情使用
   ├── README.md               ← 项目技术说明（结构/运行/功能清单）
   ├── docs/文档关系与移植说明.md ← 本文档（层级 + 移植清单）
   │
   └── 游戏本体（可执行代码）
       ├── index.html          ← 单文件发布版（双击即玩）
       └── css/js/assets       ← 源码与资源（开发用）
```

### 层级说明
1. **策划案草案 v0.1**（桌面 docx）→ 最初的**设计构想**，不完整、未落地
2. **游戏策划文档 v0.2**（docs/）→ 从**已实现游戏**提炼的**权威文档**，与代码一致
3. **README.md** → 面向开发者/使用者的技术说明
4. **游戏本体** → 可运行的最终产物

> **重要**：让其他 AI 补充剧情时，应基于 **《游戏策划文档 v0.2》**（它反映了游戏真实可实现的内容和数据结构），而不是旧草案 v0.1。

## 二、移植到另一台电脑的最小清单

### 完整版（推荐，保留开发能力）

```
复制整个"问道山海"文件夹即可，包含：
├── index.html          ← 主文件（双击即玩）
├── README.md
├── build.ps1           ← 构建工具（改源码后重新生成单文件）
├── _template.html      ← 构建模板
├── css/                ← 样式源码
├── js/                 ← 全部逻辑源码
├── assets/             ← 全部图片资源
└── docs/               ← 文档（策划案/说明）
```

### 仅游玩版（最小，30MB内）

若只想玩，只需复制：
```
index.html + assets/  （注意：assets 里是图片，必须带上）
```
> 因为 `index.html` 是单文件（已内联全部 JS/CSS），但它引用的**背景图片**在 `assets/img/` 下，所以图片文件夹必须一起复制。

### 注意事项
1. **路径**：所有资源用相对路径，复制到任意位置（如 `D:\`、U盘）都可直接运行，**无需改任何配置**
2. **双击运行**：目标电脑需有浏览器（Chrome/Edge 等），**无需安装任何软件**
3. **存档**：进度存在浏览器 localStorage（本机），换电脑不继承，属正常现象
